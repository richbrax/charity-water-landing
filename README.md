# charity: water landing page

A landing page designed for college students, built for the Global Career Accelerator
(Week 2 branding project and the Week 3 LevelUp).

## Adding the photos

The page looks for two images:

- `images/hero.avif` — the hero photo, beside "Proof, not promises."
- `images/impact.avif` — the photo in the "Clean water changes the everyday" section

Both should come from the charity: water visuals folder linked in the campaign brief.
Landscape crops work best. Until they are added, those areas show a neutral grey block
rather than a broken image.

## Adding the logo

The header and footer currently use a text wordmark. Replace both `.mark` elements with
the real logo file from the charity: water brand assets folder.

## Brand colors

| Use | Hex |
| --- | --- |
| Signature yellow | `#FFC700` |
| Teal | `#00A19D` |
| Text | `#111111` |

## Publishing

Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
